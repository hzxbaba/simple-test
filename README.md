# 行为演化图谱

基于行为动力学、压力响应模型与人工智能分析的决策行为评估工具。

## 项目简介

本系统不采用传统人格标签模式。

系统关注：

* 风险承受能力
* 长期耐受能力
* 情绪介入程度
* 规则依赖程度
* 自我一致性

结合开放问题与AI分析，构建用户在不同环境下的决策行为模型。

## 功能

* 行为倾向测试
* 雷达图可视化
* 开放问题输入
* DeepSeek AI分析
* 决策结构评估

## 技术栈

* Python
* Streamlit
* Plotly
* DeepSeek API
